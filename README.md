DarkSoundMixer

A high-performance Windows audio mixer designed for individual application volume control.
Features

    Individual Volume Control: Manage the sound levels of each running application separately.

    Discord Integration: Automatically detects and manages both your Discord main client and active voice channels as distinct, independent audio streams.

    Favorites System: Pin your essential applications to keep them at the top of your list for quick access.

    Performance Focused: Highly optimized to prevent micro-stutters and latency, ensuring smooth audio control even during CPU-intensive gaming sessions (e.g., PUBG).

    System Tray Support: Minimizes to the system tray for a clean, unobtrusive workspace.

How to use

    Download: Grab the latest release from the "Releases" section.

    Run: Simply launch the .exe file.

    Control: Use the sliders to adjust volumes in real-time. Favorite apps by clicking the pin icon.
